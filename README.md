# MURANUCI metagenomics

Downstream analysis scripts supporting the MURANUCI study of intestinal microbiota and antimicrobial resistance genes (ARGs) in intensive care unit patients from Spanish hospitals.

The analyses use Kraken2/Bracken taxonomic profiles, sequencing quality-control summaries, ARIBA–ResFinder detections and nf-core/funcscan results. They include comparisons with cultured isolates and taxonomic characterisation of ARG-carrying contigs.

## Repository contents

| File | Purpose |
|---|---|
| `TAX-TAXPROFILER/R/MURANUCI_taxonomy.Rmd` | Community composition and selected clinically relevant taxa |
| `TAX-TAXPROFILER/R/MURANUCI_sequencing_depth.Rmd` | Sequencing depth, quality-filtering retention and estimated non-host read proportions |
| `TAX-TAXPROFILER/R/functions_taxonomy_plots.R` | Shared taxonomy plotting functions |
| `TAX-TAXPROFILER/R/import_kraken.R` | Import of Kraken2/Bracken reports |
| `CONTROLES/Controles.Rmd` | Expected and observed mock-community composition |
| `ARGs/R/MURANUCI_ARG_analysis.Rmd` | ARG detections, cross-method comparisons, culture concordance and contig taxonomy |
| `ARGs/supplementary/paper_tables/generate_tables.py` | Supplementary tables from saved results and explicit curated-data CSV files |

See the [ARG analysis documentation](ARGs/README.md) for its inputs, execution instructions and output tables.

## Data availability and scope

Pipeline inputs, clinical datasets, generated analysis tables and the private sample-identifier mapping are not distributed in this repository. Selected manually curated contig findings are included as three CSV files in `ARGs/supplementary/paper_tables/curation/`; these are reviewed derived data, not the original pipeline inputs or private mapping.

The scripts require existing pipeline outputs and local metadata. Cloning the repository alone does not provide a complete runnable dataset. The private mapping associates original source identifiers with the patient and visit identifiers used in the manuscript.

These scripts do not execute ARIBA, nf-core pipelines or new BLAST searches. The Python generator reads saved BLAST alignment reports without querying NCBI.

## Software requirements

The R analyses use `tidyverse`. Additional packages loaded or called across the taxonomy, controls and sequencing-depth scripts include `ggsci`, `scales`, `cowplot`, `RColorBrewer`, `viridis`, `ggrepel`, `rvest`, `DT`, `doParallel` and `WriteXLS`. Rendering R Markdown requires `rmarkdown`, `knitr` and Pandoc. The Python generator uses the standard library.

A package-version lockfile is not currently included.

## Local execution layout

Current paths expect this repository in a local directory named `results`, with metadata in a sibling directory:

```text
study_workspace/
├── metadata/                         # Private local files, not distributed
│   ├── MURANUCI_sample_id_map.csv
│   └── MURANUCI_culture_metadata.csv
└── results/                          # This repository
    ├── ARGs/
    ├── CONTROLES/
    └── TAX-TAXPROFILER/
```

The GitHub repository name remains `muranuci-metagenomics`; `results` is the directory name expected by the current local paths. Required pipeline outputs must be available at the locations referenced in the scripts.

From R, with the working directory set to `study_workspace`:

```r
rmarkdown::render("results/TAX-TAXPROFILER/R/MURANUCI_taxonomy.Rmd")
rmarkdown::render("results/ARGs/R/MURANUCI_ARG_analysis.Rmd")
```

Run taxonomy before the ARG analysis when the derived selected-taxa table is not available. When executing individual chunks interactively, use the corresponding Rmd directory as the working directory for relative paths.

Execution writes output files and may overwrite existing outputs with the same names. The `.gitignore` excludes local inputs, generated outputs, historical files and session artifacts from version control.
